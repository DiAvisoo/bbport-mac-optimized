BLOODBORNE OPTIMIZED 0.1.1

1. Extract the ZIP and move Bloodborne Optimized.app to Applications.
   Keep your existing working app under a different name while testing.
2. Open the app, choose your own Bloodborne folder containing eboot.bin
   (base game merged with update 1.09), select a resolution, and press Play.
   First launch defaults to 1920x1080; later launches remember your choice.
3. For 3840x1080, enable Ultrawide and choose 3840x1080 (32:9).
   Quicksave/quickload is optional. Default keys: F1 settings, F2 save, F3 load.
   Click a key in the launcher to remap it.

Requires Apple Silicon, macOS 26+, and Rosetta 2. No compiler, Homebrew,
Python installation, or source checkout is needed. Tested on M2 Max 64 GB;
other Macs are untested. Reported 30–40 FPS at native 3840x1080; not a guarantee.

Settings, generated files and logs: ~/Library/Application Support/bbport/optimized-launcher
Default saves: ~/Library/Application Support/bbport/user
Existing saves are shared with your current installation. For a separate test,
choose a COPY of your saves folder under Advanced. Quicksave snapshots are
on-disk saves, not full emulator states; quickload restarts the game.

Graphical glitches after loading? Restarting the game often clears them.
First-launch shader compilation can cause pauses. 720p has also shown an
occasional startup failure; retrying can help.

This app is ad-hoc signed, not Apple-notarized. If macOS blocks it, use
System Settings > Privacy & Security > Open Anyway after attempting to open
it. Do not disable Gatekeeper. Install Rosetta through macOS if requested.

No game files, artwork, saves, personal settings, logs, or shader caches included.
Open-source license notices are inside the app. Source and build instructions:
https://github.com/DiAvisoo/bbport-mac-optimized/blob/v0.1.1/docs/release/SOURCE.md

Project: https://github.com/DiAvisoo/bbport-mac-optimized

OPTIONAL ULTRAWIDE UI FIX
With Ultrawide on and a verified game folder, choose an extracted UI mod folder.
The green check verifies its .gfx files; any aspect ratio or partial pack is accepted.
Choosing a valid folder automatically backs up and enables the downloaded UI fix.
Disable it, or turn Ultrawide off, to restore the previous files. Existing mods in
that backup are preserved. If an ultrawide UI mod was already present, removing it
requires your earlier original backups. Changing wide resolutions keeps the UI layout.
Download guide: https://www.nexusmods.com/bloodborne/mods/202
No game files, UI files, downloads, backups or saves are included in this release.
