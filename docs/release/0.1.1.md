# Bloodborne Optimized v0.1.1

Fixes the launcher startup blocker reported in [issue #1](https://github.com/DiAvisoo/bbport-mac-optimized/issues/1).

- **Play is no longer blocked by the optional UI-mod check when no UI mod is active**, even if `dvdroot_ps4/menu` is missing or linked.
- UI-mod installation still rejects missing, linked or invalid destination folders. Errors now distinguish these cases and show the full path.
- Active/interrupted installations and damaged backups still require recovery; file backup and restore protections are preserved.
- Fixed the launcher's Help → User Guide link.

The game engine, renderer and performance settings are unchanged from v0.1.0. This release fixes launcher validation; it does not repair incomplete game dumps.

## Install

Download **bbport-mac-optimized-0.1.1.zip**, extract it, and replace the previous app in Applications. Choose your complete Bloodborne game folder and press **Play**. Saves and settings remain outside the app.

Requires Apple Silicon, macOS 26+, Rosetta 2, and your own decrypted Bloodborne files with update 1.09 merged into the base game. The app is ad-hoc signed, not notarized; if blocked, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it.

For the reported error, check `<game folder>/dvdroot_ps4/menu` and select the full game folder, not the update-only folder. Restore genuinely missing game files from your own dump. The optional UI installer requires real directories rather than symbolic links.

Validation: 20 Python UI transaction/startup tests and 15 Swift launcher tests pass, including missing/linked folders, blocked unsafe installation, backup restoration and interrupted-swap recovery. Package checks verify bundled runtime startup, signatures and excluded assets.

Only the standalone app ZIP is uploaded. No game files, game artwork, UI mods, saves or personal settings are included.
