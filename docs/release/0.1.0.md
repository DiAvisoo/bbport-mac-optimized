# Bloodborne Optimized 0.1.0 — local preview

Reported by the tester: 30–40 FPS at true 3840×1080 (32:9), running beautifully on a Mac Studio M2 Max with 64 GB RAM. Performance varies by scene and cache warm-up; M1 and other Macs have not been tested.

- Native Apple Silicon GPU process with the tested KosmicKrisp driver; the game code runs under Rosetta 2.
- Correct 32:9/21:9 resolution patches and enough direct memory for their graphics heaps. 2560×720 is also available; 3840×1080 renders at full resolution without upscaling.
- Empty-draw skipping, cached guest-memory region lookup, correct compute submission ordering, and safe asynchronous shader-cache writes.
- One app: select your own game folder and press Play. Display settings and shortcut legend are visible; other settings are under Advanced.
- Optional quicksave/quickload with configurable keys. Defaults: F1 configuration, F2 save, F3 load. Saves are snapshots of the game's on-disk save, not emulator memory states; loading restarts the game.
- Bundled runtime and libraries: no Homebrew, Python installation, compiler, or source checkout needed.

Requires Apple Silicon, macOS 26 or later, Rosetta 2, and your own Bloodborne files merged with update 1.09. This build uses M2 CPU tuning; only M2 Max has been tested.

Known issue: graphical glitches or an occasional startup failure may occur after loading or changing resolution, particularly at 720p. Restarting the game often clears them. First launch prepares files and compiles shaders, so it can take longer.

This is an ad-hoc signed local preview, not a notarized public release. Nothing has been uploaded. Game files, game artwork, saves, shader caches, personal settings, and logs are excluded.
