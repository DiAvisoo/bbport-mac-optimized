# Bloodborne Optimized v0.1.0

**30–40 FPS at full 3840×1080 (32:9), without upscaling, on a Mac Studio M2 Max (38-core GPU), 64 GB RAM.** Performance varies by area and shader-cache warm-up; other Macs are untested.

- Native Apple Silicon launcher and renderer; the game's original code uses Rosetta 2.
- 16:9, 21:9 and 32:9 resolution options, including 720p ultrawide. First launch defaults to 1920×1080 and remembers later choices.
- Optional Nexus UI-pack installation with file validation, backups and reversible enable/disable. Choosing a valid folder enables it automatically. Supply your own UI files.
- Optional quicksave/quickload with remappable F1 settings, F2 save and F3 load. Quickload restores the latest checkpoint and restarts the game.
- Optimized rendering, controller handling and save snapshots; everyday settings are visible, with the rest under Advanced.
- Standalone app with bundled runtime and libraries. No compiling, Xcode, Homebrew or separate Python installation needed.

## Quickstart

Extract `bbport-mac-optimized-0.1.0.zip`, open **Bloodborne Optimized.app**, choose your game folder and hit **Play**. Have fun! For 32:9, enable Ultrawide and choose 3840×1080 before playing.

Requires Apple Silicon, macOS 26+, Rosetta 2, and your own decrypted Bloodborne files with update 1.09 merged in. No game files, game artwork, UI mods, saves or personal settings are included.

The app is ad-hoc signed, not notarized. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. First-run shader compilation can cause pauses. Graphical glitches after loading often clear after restarting; occasional startup failures have been seen at 720p.
